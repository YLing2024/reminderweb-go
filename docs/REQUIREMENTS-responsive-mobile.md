# 需求书：ReminderWeb 前端移动端响应式改造（2026-10-17）

> 来源：用户「把响应式不友好的项目都改造一下」。审计口径：真浏览器 390×844 + 生产后端真实数据（本地注入 `X-Auth-User` 的预览代理）。

## 0. 硬约束（违反即返工）

- **只动前端**（`web/`）：不得改后端、不得改 HTTP 契约、不得改备份包格式与密钥常量（硬约束 1）、不得改 schema（硬约束 2）。
- **不得引入新的 UI/路由/状态/样式库**（现有依赖之外不加；CSS Module 继续用 CSS Module，不要换成 CSS-in-JS）。
- **桌面观感必须不变**：≥992px 逐像素一致（断点只在窄屏/`pointer: coarse` 生效）。
- **禁 emoji**；文案克制；不隐藏导航（窄屏用抽屉/折叠，不要藏）。
- 源码/文档不得出现真实域名、公网 IP、邮箱、密钥、口令；示例统一 `example.com` / `127.0.0.1`。
- 小步中文提交、不带署名、**不 push**、不开分支、不 `git add` 构建产物（`web/dist`、二进制）。
- 禁止重启服务、禁止改 nginx/systemd、不许动 `/var/www`。

## 1. 实测到的问题

390×844 实测（首页：倒数日/正数日/生日卡片）：

| 项 | 实测 | 目标 |
|---|---|---|
| **可见文本 <12px** | **98 处，全是 10.92px（= 0.78rem）**，来自卡片页脚的日期与星期标签，类名形如 `_footerPrefix_*` / `_footerWeekday_*`（CSS Module） | 可见文本 **≥12px**（页脚标签 12px 即可，别跟着放大） |
| 触摸目标 | 控件 56 个，**0 个 <40px** ✅（本就达标） | 保持；新增改动不得把命中区改小 |
| 表格 | 无 | — |
| 文档级横向溢出 | 0 ✅ | 仍为 0 |

其余字号是刻意的层级：62.4px 大数字（49 处）、14px / 13px 正文、12px 次要 —— **不要动**。

## 2. 要做的

1. **把 <12px 的可见文本全部抬到 ≥12px**（重点就是卡片页脚那 98 处；顺带全仓 `font-size` 扫一遍，含 `rem`/`em`/百分比写法，别只搜 `px`）。
2. **巡视所有视图**（列表/卡片、日历、设置、关于、登录页等），逐屏确认没有 <12px 可见文本、没有 <44px 的主要操作、没有横向溢出；窄屏工具栏/按钮组换行或折叠。
3. **若发现窄屏挤压**（大数字 + 长标题同行、卡片换行错位等），按标准做法处理（换行/缩小次要信息字号至 12px 下限，不许再小）。
4. 触屏命中区顺带核一遍（主要操作 ≥44px、次要图标 ≥32×32、间距 ≥8px），**桌面尺寸不变**。

## 3. 验收（自己先跑，附原始输出）

- `make check` 全绿（`web` + `vet` + 路由文档机检 + 单测；未设 `TEST_MYSQL_DSN` 时数据库用例 skip）。
- 前端加断言测试（Vitest/jsdom 即可）：遍历所有视图，断言**可见文本字号 ≥12px** 且**表单/按钮命中区达标**；jsdom 量不到尺寸时改为断言 class/style 并在报告里说明。
- `make web`（或 `npm run build`）成功，产物 `web/dist` **不入库**。
- 自证报告 `/tmp/reminderweb-responsive-report.md`：原始命令 + 真实输出 + 未解决边界。

## 4. 追加（2026-10-17 上线后复测发现的缺口，下一轮补）

首页已达标（小字 98→0、控件 56/56 达标、桌面零漂移）。但**设置页**实测仍有：

| 位置 | 实测 | 要求 |
|---|---|---|
| 种子色输入框 `_seedColorInput_*` | **27px** | 表单控件窄屏 ≥44px |
| 行内链接按钮 `_linkButton_*` / `_linkButtonDanger_*`（各 22 个，共 44 个） | 36px | 主要行内操作（编辑/删除等）窄屏 ≥44px |
| 自定义开关 `_toggle_*`（8 个） | 32px | 触屏命中区 ≥44px（开关本体视觉尺寸可不变，扩大命中区即可） |

- 只在 `@media (max-width: 991.98px), (pointer: coarse)` 生效；桌面 1280×900 必须与现在**逐像素一致**。
- 复测口径：`/settings` 视图下统计 `button/input/select/.ant-switch` 中高度 <44 的数量，应从 53 降到 0（或仅剩明确列为"次要"的项）。
